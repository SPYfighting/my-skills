# 布局与视觉语法

## 先提炼参考，再选择版型

有参考 PPT 时，查看实际页面而不只提取文字：标题/正文比例、模块尺寸、图文比例、边框、箭头、底部结论、留白与颜色各是什么作用。沿用这些可观察的关系，不复制私人图件或把某一主题的章节结构当通用规则。

配色与字体遵循主入口的强制规则，参考模板不能自动覆盖。先按 [完整页面参考库](gallery.md) 的索引选择与当前信息关系相近的2–4张图，查看可编辑PPT及对应的全尺寸导出图；无视觉能力时读逐页布局JSON。37张示例包含科学图、解释文字和证据关系；它们示范组织方法，合成内容不能用作研究结果。

参考稿页数较多时，先通览全稿联系表，再逐页看实际画面，把不同布局及其变体列为覆盖清单；复杂页另作放大。页数很多或工具受限时记录未查看范围，继续查看与当前任务相关的页面。不要只挑最整齐的分栏页，漏掉不对称主图、多层证据、跨区汇聚、正式表格和平台界面。

## 深色信息层级

使用下列颜色角色；色值是可直接复用的基准。白色背景与中性细边框允许，不能把“允许白底”理解成允许粉蓝、粉紫、薄荷绿等淡色主题或马卡龙装饰。

| 角色 | 基准色 | 用法 |
|---|---|---|
| 标题与主要结构 | 深蓝 `#15344E` | 页标题、章节主标题、重要结构标题 |
| 主流程与模块标题条 | 深蓝 `#1F4E79` | 主箭头、流程节点、实心标题条 |
| 正文 | 黑色 `#111111` | 解释、正常字号标注及主要阅读文字 |
| 背景与深色块内文字 | 白色 `#FFFFFF` | 白底；深蓝等深色块内使用白字 |
| 关键底部结论 | 深红 `#A63237` | 设置该结论时醒目呈现；不要求每页都增加一句 |
| 必要分隔 | 中性灰 `#B7B7B7` | 细边框、分隔线，不能代替主要文字和主流程的对比度 |

内容区优先白底，依靠深色标题、文字、线条和间距形成分组；禁止用大块淡色填充、无意义渐变或多色装饰制造层次。文字进入深色块时切换为白字，并检查实际投影可读性。

科学数据色阶、类别颜色、显微图通道和原始证据图颜色不属于装饰配色，保留其科学意义及图例。不得为统一深蓝主题而伪改原图、混淆正负值或破坏类别区分；新增说明、标题条和外框仍遵循上述角色。

## 页面选择

下列是可混合、可变形的构图起点，不限制新布局。先判断内容属于过程、比较、组成、尺度变化还是单一关键证据，再选择适合的空间关系；不要先选模板再切碎研究内容。

| 任务 | 适用构图 | 每块放什么 | 需要表达的关系 |
|---|---|---|---|
| 概括章节 | 左侧主标题，右侧简洁竖向路线 | 对象/方法/检验等真实步骤 | 本章如何推进问题 |
| 比较方法或证据 | 2–4栏图文模块 | 小标题＋解释图＋关键文字＋短结论 | 并列比较或互补 |
| 说明技术路线 | 流程为主，节点内有小图，节点旁有条件/产出 | 输入、关键操作、筛选依据、输出 | 串行、并行汇合、反馈 |
| 讲一个结果 | 大证据图＋2–3块解释或补充证据 | 怎么读、观察到什么、意味着什么 | 主证据与支撑 |
| 讲系统组成 | 矩阵、分层或两组互补模块 | 资源、方法、任务、可测产出 | 组成、接口、约束 |
| 总结 | 少量综合模块＋醒目总判断 | 主要发现、意义、下一步 | 归纳，而非新增分支 |
| 原理与验证 | 上下两层，上层机制，下层实验/工程验证 | 原理图、可测指标、验证步骤 | 机制怎样被检验 |
| 问题与解法映射 | 多层逻辑梯级或对应矩阵 | 挑战、方法、评价标准、目标 | 每个方法回应哪个问题 |
| 不等量证据 | 不对称拼版，例如左侧两个小单元、右侧一张主图 | 主证据、补充观察或对照 | 面积随证据权重分配 |
| 整体与局部 | 主图＋局部放大窗，必要时多层放大 | 全貌、关键区域、尺度或位置标记 | 局部位于哪里、解释什么 |
| 方法连接多结果 | 侧边流程＋结果图阵 | 步骤和相应证据面板 | 方法与结果逐项对应 |
| 跨尺度或多约束 | 大小不同的图版或共享轴的对照图阵 | 尺度、条件、约束及统一指标 | 在什么条件下可比 |
| 平台与记录 | 场景与标注主图、文档证据与相邻判断、功能目录 | 真实对象图、功能标记、证据定位 | 能力如何使用、判断依据在哪里 |
| 实施与验收 | 正式矩阵、评价表或风险响应表 | 任务、条件、可核验输出、判据 | 任务怎样落地与检查 |
| 时间或阶段推进 | 横向阶段、时间线或带关键节点的演化图 | 阶段、转折、证据与产出 | 时间/因果关系按实际区分 |

这些组合可交叉使用：例如上层呈现整体机制，下层用不对称证据组说明验证；不需要在有限的候选版型中二选一。

不是每页都分栏。选择能表达科学关系的版型，跨页保持统一视觉语言；同一版型中的模块共用网格和基线。

## 先整合互补证据，再决定分页

每页应包含完成本页任务所需的详实内容，禁止大面积没有解释或导航作用的空白。对同一研究任务，先把对象、方法、机制、性能、对照或应用等互补角度组织在一页，通过主图与辅助图、图阵、流程结合证据或不对称拼版建立联系。不要按“每张小图一页”拆成多个稀疏页面，也不设机械的模块数或填充比例。

只有当独立科学问题、必要证据规模或放映阅读负荷确实要求分开时才拆页；拆开后每页仍要有完整判断与解释。缺少素材时主动按 [图件与证据](figures-evidence.md) 检索文献图件；仍不足则合并或精简页面。不能用缩小字体、放大空框、复制句子或无关图标补足面积。

封面用与主题直接相关的综合图、研究对象组合或总路线支撑标题；章节入口用核心路线或综合视觉揭示本章任务。两者可以比结果页简洁，但不能只留随意的几行字和大片空白。结束页以明确收束、讨论邀请或必要的主题视觉完成任务，不为追求密度硬塞新的数据。

## 模块要有内容，也要有呼吸

一个常用模块包含标题条、图像区、必要说明和底部短结论。细虚线框可把图片和正文收拢在一起，避免边框层层嵌套。图片应说明对象、过程或证据；缺少可用图片时，先按 [图件与证据](figures-evidence.md) 主动检索素材，再依据可用内容选择原图、原生示意、紧凑表格或对照关系，不硬塞装饰小图。

横向图像区用合理裁剪、组合或经科学判断可旋转的图形填好有效宽度。保留比例，避免图缩成中央小点，也不拉伸结构图。旋转坐标图、医学方向图或改变方向会改义的图时优先重新构图。

多面板数据图本身足以承载论证时可以占大部分页面；增加必要的结论和读图顺序即可，不强行再做卡片。

## 字体与尺寸

中文及中文标点使用微软雅黑（Microsoft YaHei）；英文、数字及英文标点使用 Times New Roman。没有用户明确指定其他字体时，这是强制默认。加粗和大小承担层级，不另换字体制造层级。

混排不能把整段统一设成其中一种字体。支持中西文字体槽的工具分别指定 East Asian 为 Microsoft YaHei、Latin 为 Times New Roman；否则按中英文片段设置。原生图表、表格、页码和讲稿备注同样执行。公式或这两种字体缺失的专业符号可使用必要的数学/符号字体，范围限于相应符号；外部原图中的文字不为换字体而伪造或遮改，可编辑的新增标注仍按本规则。

先确认两种字体在目标渲染环境可用，并检查实际导出。缺失时保留目标字体设置，说明缺失及替代建议，取得用户对替代字体的明确意见；不要静默退回系统字体后声称已符合要求，也不擅自下载或分发商业字体。用户已指定替代时，在同一作用范围内沿用，不重复确认。

以13.33×7.5英寸宽屏为例，以下为**实际 PowerPoint pt**的起点，须按最终显示调整：

| 元素 | 起点 |
|---|---|
| 普通页标题 | 28–34 pt |
| 章节大标题 | 36–46 pt |
| 模块标题 | 20–24 pt |
| 正文、主要图标注 | 18–22 pt |
| 全页关键结论 | 22–26 pt，至少不弱于正文 |
| 辅助标签/必要引用 | 14–16 pt，关键实验信息不能靠这一层承载 |

生成库的逻辑像素、SVG像素和PPT的pt不是同一单位；先查当前工具的单位并试渲染，不直接复制这些数值。边距约为画布宽的4%–6%、模块间距约为1.5%–3%可作为起点。

放不下时先精炼句子、改变分组和图文比例，再按独立问题及阅读负荷拆页。不要把字号一路缩小来维持固定页数，也不要把原本可同页比较的结果拆散。

## 对齐和关系图形

- 叙述性正文通常左对齐；栏底短结论与模块中心对齐；数据表按比较方向对齐。不是所有文字居中。
- 主要流程箭头使用远距离可见的实心箭身，次要引线和精细结构标注可采用较细线条。主箭头的宽度与模块大小匹配。箭头占据两端可见图形或文字之间的中点，留出间隙；不能仅对齐文本框而贴住字。
- 只有真实先后关系才串联。并行方法各自汇入筛选，反馈从检验返回待更新的步骤；返回箭头写清回传的信息。
- 加号表示合并贡献，括号覆盖所有被汇总的模块，不能只框住其中一组。环形流程和回路箭头仅在循环关系真实存在时使用，中央大圆不是表达“相互关联”的默认方式。
- 简图也应交代对象、操作和输出。只有“输入→处理→结果”且没有科学内容的方框不能充当技术路线。

## 视觉检验

先做一次“删元素”检查：框线是否有助分组，箭头是否表达关系，标题下是否还需要副标题，底部结论是否与标题重复。能省而不损失理解的元素就省；复杂内容则允许增加新的空间组织方式。

缩略图检查阅读路径、无功能留白和整稿节奏；单页正常显示检查多角度内容是否连贯、图文是否可读；放大检查裁剪和细节。章节标题应能与右侧流程抗衡，状态信息位于概括语下方等次要区域。若设置全页结论，用醒目的深红；标题已清楚表达结论时，可以不再重复底部句子。长句先精炼，再调整空间。核对深蓝、黑色、白字与深红的角色，去掉淡色主题、拟物光泽、过度圆角和无含义装饰。
