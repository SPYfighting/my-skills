# 图件与证据

## 从解释目的选择素材

优先采用适合且获授权的原始结果、文献图件、公开数据库图件和真实对象图片。用户未提供足够素材时，主动检索补齐，不把找图任务默认退回用户，也不直接用生图模型填空。

配图回答一个具体问题：对象长什么样、方法如何作用、变量如何变化、证据支持哪个判断。装饰性图片不能补足缺失的科研内容。

引用文献方法时直接解释方法如何服务当前问题，无需额外设置一页无关的外部结果介绍。确实需要比较文献结果时，明确其研究对象、条件和出处。

## 素材不足时的主动检索

1. **按解释缺口找图。** 为缺图模块明确对象、过程、结构或比较关系，再用对应的学术关键词和图件类型检索，必要时组合中英文检索词。只修改文字或箭头、现有素材已足够时，不追加无关搜图。
2. **追到一手来源。** 使用可用的文献、网页、数据库或本地文献库工具，优先原始论文的出版方页面、开放全文库、专业数据库和机构资料，查看正文图及相关补充材料。用户未限制联网或来源范围时，常规公开检索直接推进，无需逐张确认。图片搜索、综述和聚合站可作线索；最终打开原始页面或论文，核对原图、图注、相关正文及适用条件，不凭缩略图或搜索摘要判断。检索只提交必要的通用科学概念，不外传未公开数据、序列或私人材料。
3. **选取可用面板。** 优先可复用的高清图或矢量图，按实际用途核对许可及署名要求。挑出能解释本页问题的局部面板，保留影响理解的坐标、比例尺和对照；检查实际放映尺寸的清晰度。外部图用于方法或对象示意时，不把其结果带入本研究结论。
4. **落到页面和来源索引。** 保存获准使用的素材，按下表记录出处、图号、用途与处理方式，再组织进图文模块。所需解释已得到合适图件支撑即停止检索，不为数量填图。未找到时可调整关键词或寻找科学含义相当的来源；仍无合适素材时，用有依据的原生示意、表格或调整页面。受网络、权限或工具限制时说明具体缺口，继续可完成部分，不声称已检索或把受限视为生图许可。

## 生图模型的授权边界

**调用生图模型须有用户对该用途的明确要求或明确批准。** 这包括文字生成图片、参考图重绘，以及生成式扩图、补画或修复；委托其他Agent、插件或服务调用同样适用。“做得美观”“自行找素材”“用卡通风格”或“你自行决定”本身不构成生图授权。已有授权在约定范围内有效，不重复询问。

认为确需生图时，先完成能独立推进的检索与排版，集中说明拟生成哪些图、用途、现有素材的具体缺口及可用替代方案，再申请明确许可；未收到肯定答复不调用，继续其他已授权工作。获准生成的概念插图仍不能冒充实验图、结构证据或测量结果，图件身份在来源索引中准确记录。

用PPT原生图形或SVG画流程、按真实数据绘制统计图、从已知结构渲染分子图、常规裁剪和缩放，不属于调用生图模型，可按任务正常执行。这些方法应服务于真实关系与证据；不要用批量自绘装饰图取代本应进行的文献素材检索。参考库中的程序绘制合成图只用于学习布局，不是实际汇报的默认配图。

## 证据身份与来源索引

给图件或关键主张保留一条来源记录：

| 字段 | 记录内容 |
|---|---|
| 使用位置 | 页码、模块、图件文件名 |
| 身份 | 本研究观测、模型输出、外部结果、方法示意、未来计划 |
| 出处 | 用户提供的文件/数据位置，或题名、DOI/稳定URL、图号/面板 |
| 权限 | 授权范围或公开来源的适用许可；需要时记录署名要求 |
| 处理 | 裁剪/重绘/单位转换/归一化/汇总及参数 |
| 核验状态 | 原文与图注、许可、原图查看、成品尺寸检查的完成情况及未完成项；找到链接不等于已可用于成品 |
| 支撑 | 该素材支持哪一项判断，不能据此断言什么 |

索引随项目保存，不嵌入演讲备注。必要的页内引用、图内出处、许可署名和“示意/预测”等身份标签应保留，不能为了版面干净把外部结果伪装成本研究发现。仅作方法示意且不涉及结果归属时，可用简短来源标记配完整独立索引。

不能确认可复用权利时，用自绘概念图、授权替代或链接，不默认把网上图片复制进可公开传播的文件。不要把私有图件上传到外部生图或排版服务来绕过本地能力缺口。

## 重绘与裁剪

- 保留科学意义：坐标、单位、分组、样本量、误差类型、对照、归一化基准按原研究需要保留。
- 整理出用于作图的准确数据；任何汇总、变换和舍入有可复现计算，核对总数和极值等关键量。
- 图片不支持精确数值时，不能为了可编辑而凭目测造表；可保留授权原图，或明确标注并记录经过核验的数字化读图。
- 分子、仪器、细胞等示意图的部件和连接要有科学含义；不用装饰性人手或复杂物体填空。
- 有两份来源冲突时，不静默选择更好看的结果。定位冲突；能确认的先做，影响结论的点集中询问。

## 科研措辞

观测、计算和推断分别使用对应动词。模型分数、筛选信号等代理指标，未经验证不能直接解释为实验性能或目标测量量；路线可行性也不等于已完成成果。用户提供的研究进展可用于讲述，但不能自行补充数量、指标或发表状态。

禁止在页内添加制作解释、泛泛免责或重复限定；左下角、整页底部、模块或图表下方都没有例外，缩小字号、换成灰色或改称“说明/备注”也不能保留。例如“仅供参考”“仅作展示”“以实际结果为准”“不代表最终结论”不能被当作默认页脚。制作过程、素材不足和验收状态进入对用户的交付说明或独立记录，不进入幻灯片或口头讲稿。

实质科学条件用正常字号并入有关主句或紧邻解释，准确说明一次。例如写“模型预测结合评分升高，下一步进行实验测定”，不要先写“结合能力提高”，再在底部加“仅为预测、尚待验证”。模型身份、样本量、单位、误差类型、必要引用与许可署名仍准确保留；它们不等于泛泛免责。参考库的合成属性在图册说明和文件属性中统一声明，不给每页附防御性页脚。

公开可复用的模板与技能只放原创通用图形和明确标记的合成示例；不夹带个人资料、单位/合作关系、未公开数据、文件路径或图像元数据。
