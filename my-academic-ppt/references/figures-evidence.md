# 图件与证据

## 从解释目的选择素材

图件优先顺序是适合且获授权的原始结果、可追溯的公开研究图或数据、科学上准确的自绘示意图。生成插图只补充难以表达的概念，不能代替结果图、结构证据或测量数据。

配图回答一个具体问题：对象长什么样、方法如何作用、变量如何变化、证据支持哪个判断。装饰性图片不能补足缺失的科研内容。

引用文献方法时直接解释方法如何服务当前问题，无需额外设置一页无关的外部结果介绍。确实需要比较文献结果时，明确其研究对象、条件和出处。

## 证据身份与来源索引

给图件或关键主张保留一条来源记录：

| 字段 | 记录内容 |
|---|---|
| 使用位置 | 页码、模块、图件文件名 |
| 身份 | 本研究观测、模型输出、外部结果、方法示意、未来计划 |
| 出处 | 用户提供的文件/数据位置，或题名、DOI/稳定URL、图号/面板 |
| 权限 | 授权范围或公开来源的适用许可；需要时记录署名要求 |
| 处理 | 裁剪/重绘/单位转换/归一化/汇总及参数 |
| 支撑 | 该素材支持哪一项判断，不能据此断言什么 |

索引随项目保存，不嵌入演讲备注。必要的页内引用、图内出处、许可署名和“示意/预测”等身份标签应保留，不能为了版面干净把外部结果伪装成本研究发现。仅作方法示意且不涉及结果归属时，可用简短来源标记配完整独立索引。

不能确认可复用权利时，用自绘概念图、授权替代或链接，不默认把网上图片复制进可公开传播的文件。不要把私有图件上传到外部生图或排版服务来绕过本地能力缺口。

## 重绘与裁剪

- 保留科学意义：坐标、单位、分组、样本量、误差类型、对照、归一化基准按原研究需要保留。
- 整理出用于作图的准确数据；任何汇总、变换和舍入有可复现计算，核对总数和极值等关键量。
- 图片不支持精确数值时，不能为了可编辑而凭目测造表；可保留授权原图，或明确标注并记录经过核验的数字化读图。
- 分子、仪器、细胞等示意图的部件和连接要有科学含义；不用装饰性人手或复杂物体填空。
- 有两份来源冲突时，不静默选择更好看的结果。定位冲突；能确认的先做，影响结论的点集中询问。

## 科研措辞

观测、计算和推断分别使用对应动词。模型分数、筛选信号等代理指标，未经验证不能直接解释为实验性能或目标测量量；路线可行性也不等于已完成成果。用户提供的研究进展可用于讲述，但不能自行补充数量、指标或发表状态。

减少与内容无关的防御性小字，同时保留实质限定。例如用“在该测量条件下，处理组信号升高”替代泛泛的强结论；若只是预测，标题和讲稿都明确为预测。

公开可复用的模板与技能只放原创通用图形和明确标记的合成示例；不夹带个人资料、单位/合作关系、未公开数据、文件路径或图像元数据。
