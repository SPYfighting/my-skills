# 局部对象互作图

局部对象图适合小分子、辅因子、离子、单个或少数核苷酸、修饰残基、糖、脂质头基及用户指定的局部化学片段。图的中心是目标对象，周围是与它接触的残基、核苷酸或其他组分。

## 1. 冻结目标

记录输入文件及SHA-256、模型、组装体、目标对象和互作对侧。目标至少用链、作者残基号、插入码、组分名和原子范围唯一描述。对于共价修饰，同时登记宿主残基、连接原子和键。

多模型、替代构象或对称拷贝不能静默合并：选择一个并记录；需要比较时分别分析。

## 2. 建立可信拓扑

坐标文件常能提供位置，却未必提供足够的键级、芳香性、形式电荷和氢。拓扑来源按以下优先级选择：

1. 用户或项目已确认的SDF/MOL2、化学组分定义或拓扑文件；
2. mmCIF中的化学组分和共价连接；
3. 标准残基、核苷酸或序列模板；
4. 有明确警示的保守推断。

将拓扑原子映射到原结构的链、残基号、插入码和原子名。核对元素、重原子全集、重复原子、缺失原子及共价边。把原结构坐标复制到化学拓扑上，不为出图重新嵌入或优化三维构象。

共价附加基团与宿主属于一个连续目标时，合并后再做互作检测；同时在结果中保留“宿主部分”和“附加部分”的原子归属。

## 3. 检测互作

有可靠RDKit拓扑时优先使用ProLIF。根据输入是否包含经过合理处理的显式氢选择显式或隐式氢模式，并记录选择。常用类型包括：

- 候选氢键供体/受体；
- 正/负电荷接触；
- 疏水接触；
- 芳香堆积和阳离子—π；
- 范德华接触；
- 工具和对象支持时的卤键、金属配位或水桥。

开启计数模式以保留同一残基的多个原子组合。距离和角度沿用实际安装版本的互作定义；更改参数时同时记录原默认值、新值和理由。

如用户需要“所有附近对象”，可另算纯距离近接。近接必须使用独立名称和明确阈值，不覆盖或伪装成氢键、范德华或离子互作。一个残基同时有特异互作和近接时，图中优先显示信息量更高的特异互作，完整原子表仍保留全部记录。

## 4. 生成二维图

用RDKit为中心对象生成二维坐标。若对象只是较大聚合物的一部分，只画与解释相关的局部片段，并用连接标记说明截断位置。

周围节点按目标原子附近的二维位置、链/组分分区和避碰结果布置。每条边至少编码互作类型；距离只在可读时标注，完整精度保留在CSV。相同残基、相同类型的多条原子边可在图上合并，但必须保留其原子级`interaction_id`集合。

图中保留标题、目标身份、节点身份、图例和必要距离。运行名、调试编号、审核状态和内部路径放入方法记录，不占图面。图背景、颜色和字号服从用户或项目样式；没有样式时使用浅色背景、色盲友好配色和高对比文字。

## 5. 输出表

原子级表至少包含：

- `interaction_id`；
- 双方链、组分、残基/核苷酸号、插入码、原子或原子组；
- 互作类型及工具原始类型；
- 距离、角度和各自定义；
- 拓扑、质子化、近接或冲突警示；
- 是否绘入二维图及原始记录引用。

汇总表每个对象对或残基对一行，列出类型及计数、最短距离、全部`interaction_id`和说明。离子配位、共价键和非共价互作分列，避免读者把它们视为同一种边。
