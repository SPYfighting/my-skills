# 工具选择与安装

只在现有环境不能完成目标时安装。先记录系统、Python、已有包和可用命令；新依赖放入项目外或项目明确指定的隔离环境，不改系统Python。

## 路由

| 需求 | 首选工具 | 作用 |
|---|---|---|
| PDB/mmCIF读取、模型和链/残基/原子身份 | Gemmi | 保存作者编号、插入码、替代构象和坐标 |
| 小分子、核苷酸、修饰或短片段的化学拓扑与二维坐标 | RDKit | 读取SDF/SMILES/序列模板，生成二维化学图 |
| 具有可靠拓扑的局部对象与周围组分 | ProLIF | 按官方定义检测氢键、离子、疏水、芳香和范德华等互作 |
| 大分子界面或希望统一取得丰富原子接触 | PDBe Arpeggio | 从mmCIF输出原子—原子、原子—平面和其他接触JSON |
| 静态局部图 | Matplotlib、RDKit绘图 | 化学对象、残基标签、图例和连线 |
| 大界面网络图 | NetworkX配合Matplotlib，或Graphviz | 节点布局、分区和边样式 |

ProLIF可处理蛋白、DNA、RNA和配体等分子；PDBe Arpeggio适合选择一个组分或界面并枚举跨选择接触。选择依据是对象和图的表达方式，不是软件熟悉程度。

## 隔离安装

### 局部对象路线

下面是经过真实静态结构流程验证过的一组版本，不代表永久最新版：

```bash
uv venv --python 3.11 .venv-interactions
uv pip install --python .venv-interactions/bin/python \
  "prolif==2.2.1" "rdkit==2025.9.3" "gemmi==0.7.5" \
  "matplotlib==3.10.6" "cairosvg==2.8.2" "networkx"
```

Windows把Python入口改为`.venv-interactions/Scripts/python.exe`。没有`uv`时可用`python -m venv`和该环境内的`python -m pip`；不要混用系统解释器和环境解释器。

### 大分子界面路线

PDBe Arpeggio依赖Open Babel。优先按官方建议在独立Conda环境安装：

```bash
conda create -n complex-interactions -c conda-forge python=3.9 gemmi openbabel biopython
conda activate complex-interactions
python -m pip install pdbe-arpeggio matplotlib networkx
```

实际执行前读取安装版本的`--help`和接口签名；版本变化时先做一个最小真实结构探针，再决定是否复用旧参数。

## 能力探针

```bash
python -c "import gemmi, rdkit, prolif, matplotlib, networkx; print('LOCAL_MODE_OK')"
pdbe-arpeggio -h
```

记录解释器路径、包版本、安装命令和锁定清单。探针只证明软件可导入；正式能力还需要一个真实结构产生非空、可解析的互作结果。

## 输入与外传

本地安装和本地计算不需要上传结构。网页服务、远程API或在线绘图只有在用户明确允许数据外传时使用，并记录发送的结构范围和目的地。
