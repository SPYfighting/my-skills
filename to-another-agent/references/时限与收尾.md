# Agent 工作时限与收尾

仅当用户明确规定当前或下一位 agent 的工作结束时间、工作时长或收尾时间时使用。项目、实验或对外交付的截止日期只写入 task 用于排序，不自动触发本规则。

把相对工作时限转换为带时区的绝对时间，并在项目指定的 handoff 和当前任务记录中同步记录；沿用项目原生文件，不为时限另建 task：

```markdown
- 接手时间：2026-11-11T12:00:00+08:00
- 结束时间：2026-11-11T13:00:00+08:00
- 收尾开始：2026-11-11T12:48:00+08:00
- 收尾策略：auto
```

用户没有指定收尾预留时：

```text
预留分钟 = ceil(工作窗口分钟 × 20%)，限制在 10–30 分钟
收尾开始 = 结束时间 - 预留分钟
工作窗口不足 10 分钟时立即收尾
```

接手时和开始新步骤前核对时间。预计无法在收尾开始前完成的高风险步骤不启动；到达收尾开始后完成当前可安全结束的原子动作，更新证据、任务状态、handoff 和提示词。

活动服务器任务继续运行，按 `remote-work.md` 记录接管信息，不因 agent 工作时限强杀进程。
