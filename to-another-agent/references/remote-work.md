# 远程任务交接

用于远程服务器、集群调度器、云端工作流、后台进程、另一个 agent 会话或其他跨会话运行的任务。

## 先观察，再记录

使用项目已有的只读状态命令或日志入口核对现场。记录“最近一次观察到的状态”，不要把旧日志、提交时状态或推测写成当前事实。无法访问远端时标为“未核实”，并把首次状态检查列入“接手先验收”。

默认保留仍有价值的任务运行。停止、取消、重启、重新提交或删除远程产物会改变现场，只在既有授权覆盖时执行。

## 每个活动任务记录

```markdown
### <任务名称>

- 平台或主机：可公开的主机别名、集群或服务；不记录凭据
- 任务标识：job/run/session/process ID，未知则明确写“未知”
- 工作目录或项目：远端工作目录、仓库和版本
- 启动方式：已知且可安全复用的命令、脚本或工作流入口
- 当前状态：排队 / 运行 / 等待 / 失败 / 完成待取回 / 未核实
- 最近核查：YYYY-MM-DD HH:MM +时区，以及状态来源
- 日志或输出：路径、对象存储位置、任务页面或结果接收位置
- 监控方式：只读命令或页面入口，以及合理核查频率
- 接管动作：下一位 agent 的第一步和成功信号
- 停止条件：完成、失败、超时、资源异常或用户定义阈值
- 风险与边界：资源成本、可重复提交风险、数据外传限制、未确认配置
```

若有多个相互依赖的任务，补充依赖顺序。若结果需要从远端复制回来，写明目标位置与完整性检查方法。

## 凭据与敏感信息

只记录凭据名称、配置位置或获取渠道，例如“使用现有 SSH 配置别名 `lab`”。访问令牌、密码、私钥、cookie、带签名下载地址和完整连接字符串不进入交接文件或提示词。
