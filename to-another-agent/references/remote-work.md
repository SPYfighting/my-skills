# 服务器与后台任务

用于仍在服务器、集群调度器、云端工作流或后台进程中运行的任务。

跨 agent 交接时默认保持任务运行。不要因为会话结束而停止、取消、重启或重复提交；只有用户明确要求，或继续运行存在明确安全风险时才改变进程状态。

## 每个活动任务记录

```markdown
### <任务简称>
- 任务标识：<job ID、PID、run ID 或会话名>
- 当前状态：<排队、运行、等待结果、失败待查等>
- 最近核查：<带时区时间>
- 日志或输出：<路径或入口>
- 监控方式：<查看状态和日志的只读命令>
- 接管动作：<下一位首先做什么>
- 停止条件：<正常完成、失败阈值或用户明确要求>
```

不记录密码、令牌、私钥或临时授权链接。需要连接方式时只写主机别名、工作目录、调度器和凭据位置说明。

下一位提示词只需说明任务仍在运行、应先做的只读检查，以及完成或失败后如何接收结果。服务器任务本身不会触发额外角色或审查流程。
