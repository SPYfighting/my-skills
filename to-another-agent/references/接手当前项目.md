# 接手当前项目

用于用户要求当前 agent 接手已有项目并继续工作。这里的目标是执行项目任务，不是先生成一次新的交接。

## 读取顺序

1. 项目级指令，例如项目根目录的 `AGENTS.md`、`CLAUDE.md` 或等效文件。
2. 用户点名的交接文件；否则读取项目规则或入口文档声明的当前 handoff。仍未声明时，查找根目录现有 `HANDOFF.md`、`handoff.md` 或等效活动文件，不默认某个固定文件名。
3. 项目规则、handoff 或任务索引指向的 task/plan、状态表、结果与验证记录；尊重它们的职责分工，不把 handoff 摘要当作唯一事实源。
4. 与当前首个待办直接相关的产物、代码、数据、日志和版本状态。
5. 活动服务器任务的状态与日志入口；按 `remote-work.md` 接管观察，不重启或重复提交。

只做能够安全继续所需的现场核对，然后持续推进用户要求的工作。现有记录和实际现场不一致时，以实际现场为准并修正记录。

## 结束或换手

任务完成、实质受阻、到达用户指定的停点或用户要求再次换 agent 时：

1. 更新实际完成项、验证证据、未完成任务和服务器任务状态。
2. 按 `继续交接.md` 更新同一套项目原生 handoff/task；用户要求审查时改按 `提交审查.md`。
3. 在回复末尾用 `text` 围栏代码块给出与文档一致的下一位 agent 提示词。

不要在刚接手时因为本技能被加载而重新生成交接文件；先做项目工作。
