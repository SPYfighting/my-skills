# 开书方法

开新书时用此方法：定选题 → 轻量建对标 → 建总纲 → 建角色 → 建首批细纲。每本书只完整跑一次，开新卷时增量补充。

## 第 1 步：定选题

问作者三个问题，答案写进 `设定/题材定位.md`：

1. **想让读者什么感觉？**（核心情绪：爽/燃/甜/悬/虐……本书的情绪理由）
2. **什么题材？**（命中 `题材卡/` 的，加载对应卡片做正文底色）
3. **有没有对标书？**（同题材看过的爆款参考，没有就跳过）

**完成标准**：题材定位.md 落地（题材 + 核心情绪 + 主对标书字段）。

## 第 2 步：轻量建对标（三件套）

产出「情绪模块 / 节奏 / 文风」三件套，是后续写作与讨论的地基：

- **有对标书**：作者提供对标书信息（书名 + 能回忆的桥段，或直接给文本），agent 提炼：
  - 读者需求 → 情绪引擎（读者看这本图什么，本书如何满足）
  - 可复现模块（对标的爽点套路骨架，换素材用）
  - 节奏要点（钩子频率、爽点间隔、压抑/释放的节拍）
  - 文风（句式、叙述风格、对话风格）
  写进 `设定/对标.md`（情绪模块 + 节奏）和 `设定/文风.md`。
- **无对标**：`设定/对标.md` 写「无对标，按通用节奏自排」；文风用通用模板 + 作者口述（喜欢的作者/文风、禁忌）。节奏参照下方「通用节奏基线」。

**通用节奏基线**（无对标时用）：开篇 5 章内立金手指 + 首个爽点；每 3-5 章一个中爽点，每卷一个大高潮；爽点兑现间隔不超过 5000 字；压抑不过 3 章必给释放。

**完成标准**：对标.md 与文风.md 落地，且写正文时能据此判断「这句像不像本书」。

## 第 3 步：建总纲

按五步法建 `大纲/大纲.md`，模板见 `项目结构.md`：

1. **定高潮**：本卷最大冲突是什么（最大规模、最多人物、最强情绪）。
2. **定单元剧**：把卷拆成几个剧情单元，每个单元必须展示金手指的**新用法**，相邻单元金手指逻辑不重复，单元间有因果关系。
3. **定故事线**：主线（爽点驱动）为主，搭配感情线/对立线/成长线，明确每条线的推进节点。
4. **定开篇**：情节钩子 → 迅速进入异常状态 → 获得/介绍金手指 → 矛盾出现 → 目标建立。开篇预埋期待感（升级暗示、新线索暗示）。
5. **定收尾**：解决高潮 + 主角获得奖励 + 为下一卷铺垫。

**完成标准**：大纲.md 含题材核心梗、金手指骨架、卷划分、爽点节律、主线×支线表。

## 第 4 步：建角色

建主角 + 核心配角，按 `项目结构.md` 的角色档案模板写 `设定/角色/{角色名}.md`。

**每个角色必须能回答**：他要什么（动机）、怕什么（弱点）、藏什么（秘密）、怎么说话（语言风格）。

**完成标准**：核心角色档案落地，含基本信息/外在表现/内在分析/语言风格四块。

## 第 5 步：建首批细纲

按 `项目结构.md` 的细纲模板，建前 5-10 章细纲。每章细纲要能回答：这章交付什么情绪、发生什么事件、结尾留什么钩子、禁止提前释放什么。

**完成标准**：前 5-10 章细纲落盘。**默认停在细纲交付，不自动写正文**——作者确认方向后再进日更。
