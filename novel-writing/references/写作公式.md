# 写作公式

写每章正文时查的通用公式：钩子怎么选、爽点怎么兑现、情绪节拍怎么走。题材层面的指引在 `题材卡/` 下对应题材的卡片，两者配合：题材卡管「这题材该写什么」，本文件管「这一章怎么立起来」。

## 题材卡怎么用

写正文时三件套配合：**细纲（写什么）+ 题材卡（题材味对不对）+ 本书文风（笔调对不对）**。

- 先读 `设定/题材定位.md` 确认题材，再只读 `题材卡/{题材}.md` 那一张，不整套加载。
- 跨题材时：主题材读 1 张完整卡，辅题材读 1 张并只摘 1-2 条「常见场面/禁止漂移」。
- 每章只用题材卡里的本章相关条目（题材限制、读者期待、核心爽点、场景颗粒、禁止漂移），不整张照搬。
- 题材卡只在内部校准题材味，**绝不出现在正文里**（不写卡名、条目编号、置信度、证据摘要）。
- 冲突时优先级：章节细纲与连续性 > 情绪/节奏 > 题材卡 > 本书文风 > 通用公式。

## 决策路由：先定本章情绪，再选钩子

| 本章情绪/阶段 | 章尾钩子选 | 为什么 |
|---|---|---|
| 悬念/未知 | 突然揭示 / 留白 | 激发好奇 |
| 紧迫/危机 | 紧急危机 / 倒计时 | 制造焦虑 |
| 反转/真相 | 身份反转 / 隐藏含义 | 颠覆认知 |
| 情感/关系 | 两难抉择 / 情感转折 | 拉扯情绪 |
| 氛围/日常 | 意象钩子 / 信息差 | 暗流涌动 |

## 章首钩子（7 式）

1. **悬念对话开局**：直接从意味深长的对话开始。
2. **闪前碎片**：先给结果碎片，再回正常叙事。
3. **倒计时开局**：开头就建立紧迫感。
4. **神秘独白**：第一人称诡异内心独白。
5. **反差场景**：两个截然不同的场景并列。
6. **未完成动作开局**：动作进行中被截断。
7. **意象预示**：用环境意象暗示即将发生的事。

## 章尾钩子（13 式）

1. **突然揭示**：抛出改变全局的信息。
2. **紧急危机**：下章必须回应的紧迫威胁。
3. **未完成动作**：动作被新变量打断。
4. **身份反转**：身份真相偏离读者预期。
5. **两难抉择**：被迫在两个坏选项中选一个。
6. **神秘物品**：重要但含义未知的物件。
7. **倒计时**：时间不够用。
8. **承诺/威胁**：有人宣布了行动意图。
9. **离奇消失**：不可能的消失。
10. **隐藏含义**：表面正常，实际暗藏信息。
11. **意象钩子**：反复出现的意象发生变化。
12. **回声钩子**：章尾句呼应开头，关键细节变了。
13. **留白钩子**：只展示反应，不揭示发生了什么。

## 爽点公式

爽点不是「主角赢了」，是**读者欲望被精确兑现**。四要素缺一不可：

1. **欲望**：读者先有明确渴望（打脸、翻盘、感情回应）。
2. **障碍**：兑现前有真实阻力，阻力越大兑现越爽。
3. **兑现**：用可见结果兑现（数据、反应、身份变化），不靠宣告。
4. **余韵**：兑现后给旁观者反应（震惊、后悔、折服），放大快感。

**规则**：主角永不失态（用动作替代情绪）；先让对手得意再翻转；爽点必须通过可见变化兑现，不能只靠系统播报/内心独白。

## 期待感公式

读者追读 = 期待未兑现。三件套：

- **目标**：明确的、有进度的目标（不是模糊的"变强"）。
- **障碍**：每章的阻力在升级，而不是原地打转。
- **可见进度**：每章结束，读者能感到目标近了一点（数字、关系、地位、信息的变化）。

## 情绪节拍

- **压抑 ≤ 3 章必释放**：持续压抑超过 3 章，读者流失。
- **爽点间隔 ≤ 5000 字**：高压/推进章必查，低压/关系章不计入。
- **呼吸章克制**：低压/过场章合计不超一卷的约 15%。
- **情绪曲线**：小挫折里的疲惫/窘迫 → 问题解决后的温馨/从容，释放要细，不靠总结"生活真好"。

## 约束规则

- 相邻章节的爽点实现方式不重复（同一种打脸方式连用 = 套路）。
- 后续剧情情绪值不能显著低于前序（爽感只能递进或持平，不能断崖）。
- 剧情推进时空关联 ≥ 1:3（每 1 个因果推进，至少配 3 个场景/细节推进，防止干巴巴赶剧情）。

## 深度技法（精修或卡文时按需加载，不每章读）

上列公式够把一章「立起来」。要「写得好」时，按需读下列技法文件：

- `dialogue-mastery.md`（对话掌握）：对话怎么推进剧情、怎么带潜台词、怎么分声线。
- `reversal-toolkit.md`（反转工具箱）：反转怎么埋伏笔、怎么铺、怎么爆。
- `opening-design.md`（开篇设计）：黄金三章怎么设计、钩子怎么排。
- `emotional-arc-design.md`（情绪弧设计）：人物情绪弧怎么拉、怎么收。

卡文、某段写不好、或精修已写章节时，加载对应文件；日常日更不必读。
