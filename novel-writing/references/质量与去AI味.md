# 质量与去AI味

正文的质量检查与去 AI 味，两种场景通用：① 写完一章后的自查（日更流程第 7 步）；② 作者要「审查/帮我看看这本书」时的独立审稿。步骤：先跑脚本，再按清单自查，最后处理 AI 味。4 个脚本全部用 Node 运行，只报告不改写（normalize-punctuation 除外）。

## 一、跑脚本（顺序固定）

脚本位于本 skill 目录的 `scripts/` 下，与项目目录不共根——**在项目根目录运行**，用脚本绝对路径调用（把 `<skill目录>` 换成实际路径）：

```bash
# 在项目根目录执行
# 1. 细纲照搬检测（正文是否把细纲句子誊抄进来了，需指定细纲对照）
node "<skill目录>/scripts/check-outline-copy.js" --outline 大纲/细纲_第NNN章.md 正文/第NNN章_标题.md

# 2. AI 味模式检测（blocking 类必须改，advisory 类读语境判断）
node "<skill目录>/scripts/check-ai-patterns.js" --check --fail-on=blocking 正文/第NNN章_标题.md

# 3. 模型退化检测（复读/截断/工程词泄漏，如「细纲」「本章」漏进正文）
node "<skill目录>/scripts/check-degeneration.js" --check 正文/第NNN章_标题.md

# 4. 标点规范化（机械兜底：清省略号/破折号，保留引号风格）
node "<skill目录>/scripts/normalize-punctuation.js" 正文/第NNN章_标题.md
```

脚本报告有命中时：blocking 级改正文并复扫，advisory 级先通读判断再改。**只报不改不算完成。**

## 二、质量自查清单

### 章节结构
- [ ] 开头有钩子（不从天气/风景/日常开场）
- [ ] 中段有推进（本章至少改变目标/风险/信息/关系/资源/身份/情绪之一）
- [ ] 局势有变化（读完这章，世界跟之前不一样了）
- [ ] 结尾落在变化上（不是总结，不是「他不知道的是……」预告）

### 信息传递
- [ ] 没有大段设定说明文（信息跟着冲突走）
- [ ] 一章新概念不超过 3 个

### 语言
- [ ] 没有空洞抒情段落，情绪通过动作落地（不直接写「他很难过」）
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 正文无章节/写作元信息泄漏（不得出现「细纲」「本章」「伏笔」「读者」等词）

### 水检测（命中即压缩或删除）
- [ ] 全章对话没有任何新信息
- [ ] 同一个情绪写了 3 段以上
- [ ] 场景描写超 500 字但不推进剧情
- [ ] 角色回忆旧事但没有任何新视角

### 黄金三章（开书时）
- [ ] 第一章前 500 字有钩子、主角出场、有事件
- [ ] 前三章至少 2 个爽点
- [ ] 每章结尾有继续看的理由

### 节奏
- [ ] 最近 5 章有明确进展
- [ ] 爽点间隔 ≤ 5000 字（高压/推进章必查）
- [ ] 无连续 2 章没有冲突（呼吸章正常，红线是连续低压）

### 连载连续性
- [ ] 没有遗忘之前的承诺/伏笔（对照状态卡「活跃伏笔」）
- [ ] 没有突然塞入大量新设定
- [ ] 伏笔有推进（本章至少推进或回收一条）
- [ ] 故事引擎还在运转（主线目标未断）

### 人物
- [ ] 主角行为符合人设（OOC 即修）
- [ ] 配角有存在感，反派逼格匹配当前阶段

## 三、去AI味规则

### 最毒句式（出现即修，最高优先级）

| 毒级 | 句式 | 修法 |
|---|---|---|
| ★★★★★ | 「不是A，而是B」（「而」可省略） | 直接写 B |
| ★★★★ | 「，带着……」万能状语 | 删状语留主句 |
| ★★★★ | 「声音不大，却带着……」/「语气毫无波澜」 | 直接写台词内容或动作 |
| ★★★★ | 「他/她知道……」 | 用行为展示认知 |
| ★★★ | 「仿佛/犹如……一般」 | 删掉或白描 |
| ★★★ | 「眼中闪过一丝……」「嘴角勾起一抹……」 | 换具体动作（他垂下眼） |
| ★★★ | 「心中涌起一股……」「心头一震」 | 用身体反应 |
| ★★ | 「命运/棋局/獠牙」「反击才刚刚开始」 | 回到可见的动作/后果 |

### 一级禁用词（出现即替换）

仿佛、犹如、宛若、如同、一丝、一抹、些许、隐约、毫无征兆、微不可察、不禁、深吸一口气、眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩、指节泛白、目光锐利、心中一动、心头一震、心下了然、心中暗道、不由得、不容置疑、显而易见、前所未有、坚定、闪烁着光芒、狡黠、深邃、凛冽、不由自主、情不自禁、话锋一转

### 密度词（高频时替换，不是绝对禁用）

突然、陡然、猛然、瞬间、猛地、好像、似乎（真实突发/口语可保留）；缓缓、微微、轻轻、淡淡（每千字合计 ≤ 3）

### 标点

正文禁用破折号 `——`、双连字符 `--`、省略号停顿，改用句号/逗号/短句/动作断句。
