# 项目结构

本书项目的目录约定与每个文件的字段模板。开书时按此建目录，每次创建/更新文件时按此对照。

## 目录树

```
{书名}/
├── 大纲/
│   ├── 大纲.md            # 总纲：题材核心梗、金手指、卷划分、爽点节律
│   ├── 卷纲_第X卷.md      # 卷纲：核心矛盾、压力级分布、卷契约（见下方模板）
│   └── 细纲_第NNN章.md    # 每章细纲（三位数编号）
├── 设定/
│   ├── 题材定位.md        # 题材、核心情绪、主对标书（开书时定）
│   ├── 对标.md            # 情绪模块 + 节奏要点（开书时建，见下方模板）
│   ├── 文风.md            # 本书笔调（开书时建，见下方模板）
│   ├── 关系.md            # 角色关系网
│   ├── 世界观.md          # 世界设定、金手指、力量体系
│   └── 角色/{角色名}.md   # 每个角色一份档案
├── 正文/
│   └── 第NNN章_标题.md    # 每章正文（三位数编号 + 标题）
└── 追踪/
    ├── 上下文.md          # 续写状态卡（7 栏，唯一上下文锚点）
    ├── 伏笔.md            # 伏笔当前状态表
    ├── 时间线/
    │   ├── 作者真相.md    # 客观事实对照表
    │   └── 读者已知.md    # 读者视角时间线
    ├── 角色状态/{角色名}.md  # 每个角色一份当前快照
    └── 逐章记录/          # 每章一条增量记录（历史档案）
```

## 追踪文件写作纪律（替代脚本的保证）

没有脚本校验，靠纪律保证一致性，每条都不可省：

1. **每章一次集中更新**：写完正文后，一次性更新状态卡 + 角色状态 + 伏笔 + 时间线 + 逐章记录，全部改完后按下方「自校对清单」逐项核验。
2. **状态卡控字数**：`上下文.md` 目标 8KB，硬上限 12KB，只放「下一章真正需要的」状态。
3. **回炉重推**：修改第 N 章后，必须把状态卡、角色状态、伏笔、时间线逐条重推到最新章，不能只改第 N 章那一处。
4. **约束退役显式化**：状态卡「长期约束」栏里不再成立的条目，要明确标「已退役」并注明因哪章退役，不静默删除（否则日后查不清这条是失效了还是漏记了）。
5. **伏笔回收同步三处**：伏笔在正文回收后，同步改①`伏笔.md` 状态改「已回收」、②`时间线/作者真相.md` 揭示状态改「已揭示」、③状态卡「活跃伏笔」栏移除。三处缺一，下一章就会写错。

### 自校对清单（每章更新追踪后逐项核验）

- [ ] 状态卡「当前位置」的当前章号 = 刚写完的章号
- [ ] 「活跃伏笔」与 `伏笔.md` 里「已埋」状态的条目一致（无遗漏、无重复）
- [ ] 状态卡「截至章节」、各角色状态「截至章节」都推到最新章
- [ ] 本章新埋的伏笔已进入 `伏笔.md` 和状态卡「活跃伏笔」
- [ ] `上下文.md` 未超 12KB

## 大纲.md 模板

```markdown
# 大纲·全书卷级鸟瞰

## 题材核心梗
| 层级 | 内容 |
|---|---|
| 主题 | （一句话：本书在讲什么） |
| 题材核心 | （题材 × 元素 × 爽点来源） |
| 核心情绪 | （读者追这本书的情绪理由） |

## 金手指骨架
（金手指机制 + 升级节奏）

## 期待债与终局储备
- 期待债：（读者此刻期待但还没兑现的承诺，兑现前不能忘）
- 终局底牌：（为结局预留的伏笔/升级台阶，提前布局，收尾时用）

## 卷划分
### 第X卷：卷名
- 卷范围：第 X–Y 章
- 本卷定位：（这一卷完成什么）
- 核心走向：（主线推进）
- 收卷节点：（卷末大事件/状态跃迁）

## 全书爽点节律
（爽点循环结构：升级→危机→翻盘→再升级，阶梯上升）

## 主线 × 支线结构
| 线 | 内容 | 功能 |
|---|---|---|

## 文风参考
（本书笔调；有对标书则注明，无则写「本书自续写，见 设定/文风.md」）
```

## 卷纲模板（大纲/卷纲_第X卷.md）

```markdown
# 卷纲·第X卷：卷名

- 卷范围：第 X–Y 章
- 核心矛盾：（本卷的主冲突是什么）

## 卷契约（本卷对读者的承诺，不可违背）
- 爽点类型 / 情感基调 / 兑现节奏

## 逐章压力级分布
| 章段 | 压力级 | 章节定位 |
|---|---|---|
| 第X–Y章 | 低/中/高 | 铺垫/推进/高潮/呼吸 |

（这个分布支撑细纲的「阶段位置」字段和写作公式的「情绪节拍」规则）

## 禁止提前释放
（本卷哪些真相/能力/关系不能过早揭示，对应各章细纲「本章禁止提前释放」的上限）

## 收卷节点
（卷末大事件 + 状态跃迁）
```

## 细纲模板（细纲_第NNN章.md）

```markdown
# 细纲（第 N 章）

### 第N章：标题
- 阶段位置：（开篇期/发展期… · 第X阶段第X章；本章在卷中的位置）
- 本章结构公式：（本章节奏骨架，如「铺垫+推进+爽点兑现」）
- 本章禁止提前释放：（本章只立什么、不泄露什么）
- 核心事件：（本章发生的事，按顺序列）
- 章首钩子：（怎么抓住读者）
- 爽点：（本章爽感兑现点）
- 章尾钩子：（留下什么悬念）
- 出场角色：（按出场顺序）
- 字数目标：约 N 字

#### 情节细化
1. （事件）【起因/发展/转折/高潮/结尾·标注】

#### 结尾设定和钩子
- 收束状态：（本章结束时的局面）
- 未解决问题：（留到下一章的悬念）
- 下一章推动力：（承接什么）
```

## 角色档案模板（设定/角色/{角色名}.md）

```markdown
---
name: {角色名}
---
# {角色名}

## 基本信息
- 身份：（职位/出身/社会关系）
- 核心特质：（这个角色区别于他人的本质，一两句）
- 当前能力：（技能/资源/金手指，标注获得章）
- 核心动机：（他真正想要什么，表层 + 深层）
- 弱点/缺陷：（会被利用或导致犯错的地方）

## 外在表现
- 身份/外貌：（视觉记忆点）
- 行为习惯：（标志性动作、处事方式）

## 内在分析
- 性格：（外壳 vs 内核，矛盾面）
- 目标：（表层 + 深层）
- 秘密：（不能让他人知道的，标注是否为作者真相）

## 语言风格
- 日常/内心：（短句/口头禅/思维节奏）
- 对不同人说话：（对象 → 风格差异）

## 出场记录
| 章节 | 关键事件 | 状态变化 |
|---|---|---|
```

角色档案是「角色代入推演」的素材基础——性格、目标、秘密、弱点、语言风格，就是推演行为所需的全部约束。

## 伏笔表模板（追踪/伏笔.md）

```markdown
| ID | 内容 | 埋设章 | 计划回收章 | 状态 | 重要度 | 最近变更章 |
|---|---|---|---|---|---|---|
| F001 | （伏笔内容） | 第X章 | — | 已埋/已回收 | 高/中/低 | 第X章 |
```

## 时间线模板

```markdown
| ID | 首次登记章 | 故事时间 | 涉及角色 | 客观事实 | 读者当前认知 | 揭示状态 | 实际揭示章 |
|---|---|---|---|---|---|---|---|
| E001 | 第X章 | （故事时间） | （涉及谁） | （真实发生的） | （读者目前以为的） | 已揭示/未揭示 | 第X章 / — |
```

`读者已知.md`（读者视角，只记读者已经看到的事实，不写作者真相）。
