# 扫榜与选题

开新书前想判断「写什么能爆」时用。本文件只含方法论：拿到榜单数据后怎么分析、怎么选题。数据来源靠你提供——**没有自动化抓取脚本**，榜单数据请手动粘贴，或用联网搜索补充（搜索结果要标注时效）。

## 核心信念

**单本排名只是线索，跨样本重复模式才算信号。** 一本书上榜可能是个例；多个榜单、多本书重复出现的题材/人设/切入点，才是真实需求信号。

## 第 1 步：拿数据

- **手动粘贴**：把榜单（起点/番茄/晋江/七猫等）的书名+题材+简介粘给 agent，越全越好。
- **联网搜索**：搜「XX平台 排行榜 2026」等，拿到二手榜单盘点、媒体分析。**必须标注数据日期**，过期数据要提示。
- 数据不足时诚实说明「样本不够，结论只能算方向，不算判断」。

## 第 2 步：分析

1. **三级分类**（判断一个现象值不值得跟）：
   - 新题材：极少见，只有跨榜单、跨作者重复出现才标为趋势，否则只是观察项。
   - 新金手指：较少，多翻新，可作低成本验证点，但要换题材外壳和情绪触发方式。
   - 新噱头：常见，同质化风险高，没有差异化机制就降低优先级。

2. **目标读者画像**：用 9 维画像定位（平台/标签/阅读量/性别/年龄/地域/学历/阶层/社会角色）。读者共鸣按 **70/20/10** 配比：70% 怀旧元素（读者有过的经历）+ 20% 当前生活（正在面对的压力）+ 10% 热点话题。

3. **平台调性**（影响节奏和写法）：
   - 起点男频：三章一爽点、十章一大高潮；雷区绿帽/憋屈/女主压过男主。
   - 番茄：每章有爽点、3000 字内必爆；雷区慢热、虐主、费脑。
   - 晋江女频：人设立住、虐后必甜；雷区傻白甜、渣男不追妻。
   - 知乎盐言：前 500 字定生死，情绪拉扯 + 反转。

## 第 3 步：选题四步

每个推荐选题走完四步，缺一不可：

1. **能爆的原因（先当假设）**：从重复出现的样本提取「这个方向为什么吃这波读者」，标「待验证」。
2. **市场验证**：同方向有几本、趋势（↑/→/↓）、有没有扑街反例。
3. **差异化定位**：作者优势 × 市场缺口 = 你的版本和榜上现有的不同在哪。没有差异化 = 挤不进去。
4. **可行性 + 风险 + 验证动作**：可行性分高/中/低——样本 ≥15 本且趋势稳才可给「高」；数据不足、纯凭知识时**一律给「中」**，不许用几条数据撑出假信心。附最可能的失败点 + 低成本验证动作（通常「先写黄金三章测追读」）。

## 输出

产出 2-3 个选题，按可行性排序，写 `选题决策.md`（放在项目根或扫榜目录）：

```markdown
# 选题决策：{方向}
- 扫榜日期：{YYYYMMDD}     # 标注时效
- 数据来源：{手动粘贴 / 联网搜索，注明日期}

## 推荐选题
### 选题 1：{一句话方向}
- 题材组合 / 目标读者 / 核心卖点
- 能爆的原因：{假设，待验证}
- 差异化定位：{和榜上现有不同在哪}
- 可行性：高/中/低 — {理由}
- 失败风险 / 验证动作
```

开书时 `开书方法.md` 会读取这份选题决策作为起点。
