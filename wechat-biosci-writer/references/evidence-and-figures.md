# 证据与文献 Figure

本文件是事实核验、科研措辞和图片许可的权威规则。先完成来源地图与主张清单，再写面向读者的正文。

## 资料覆盖声明

将实际读到的材料标为以下一种，并写入 `资料与证据.md`：

- **全文与补充材料齐全**：可讨论正文、补充结果和方法细节。
- **仅全文**：不能声称系统检查过补充参数或补充实验。
- **仅摘要、项目页或二手材料**：只能作有限解读；标题、摘要和正文均不得伪装成全文拆解。
- **用户内部材料**：按用户授权范围使用，不默认公开原始内容。

来源优先级依次为：原始论文与补充材料；官方代码、文档和数据；权威数据库；独立验证；高质量二手材料。当前版本、发布日期、价格、人员和机构信息必须核对当前一手来源。

## 关键主张清单

每个会影响读者判断的结论建立一行。正文小节可以包含背景叙述，但标题、摘要、核心数字、比较结果和适用边界必须可追溯。

| 编号 | 拟写主张 | 来源与位置 | 证据身份 | 允许措辞 | 限制或替代解释 |
|---|---|---|---|---|---|
| C1 |  | S1，Fig. 2b | 实验结果 / 模型预测 / 作者声明 / 编辑分析 |  |  |

证据身份不得混写：

- **实验结果**：说明对象、对照、样本或条件；不把体外结果直接外推到临床或生态效应。
- **计算结果**：说明指标实际衡量什么；不把模型得分、结构预测或相关性写成实验验证、机制或因果。
- **论文作者解释**：可写“作者认为”或“作者提出”，不能升级成独立证实。
- **用户陈述**：保留其身份和公开边界；未有外部证据时不改写为来源事实。
- **编辑分析或推断**：明确写成“本文判断”“一种可能解释”或“基于上述结果推断”。

优先使用原始来源实际采用的效应量、置信区间、基线和评价口径。百分比必须说明分母或比较对象。名称、数字、单位、序列、标识符和坐标逐字核对；涉及转换或计算时用代码验证，并在工作文件记录输入和结果。

5. 版权清晰且确有教学作用的通用概念图。

用户给出论文文件，或能合法取得全文时，优先检查论文 Figure。只有图能承担核心证据或显著降低理解成本时才收入正文；不为凑数量配图。

## 许可与处理

- **允许发布**：用户明确拥有权利或授权；公有领域；许可条款允许当前用途。记录许可名称、链接和核对日期。
- **许可不明确**：原图只放在 `资料参考图/`，不得被 `公众号文章.md` 或发布 HTML 引用。发布版制作原创解释图，并保留来源标注。
- **明确禁止或无法合法取得**：不下载、不收入发布包；用文字或原创示意替代。

裁切不得移除理解数据所需的坐标、图例、组别、误差或限定。拼接、重绘、颜色调整和数据再绘制均须标明“改编自”或“根据……整理”，且不得制造原文没有的精度。原创图也要记录事实来源和制作方法。

封面与正文图分开判断。论文 Figure 适合作为证据，不代表适合作为封面；默认使用原创、版权清晰的封面。

## 面向读者的图注

图注使用原创表达，通常包含四项：

1. 读者先看什么。
2. 图中比较或流程是什么。
3. 它支持正文哪个判断。
4. 来源、Figure 编号和必要的许可或改编说明。

不要复制论文原图注。重要限制紧邻图片写入正文，不把所有边界藏到文末。

## 引用与可追溯性

正文的 DOI、项目主页、官方文档和代码仓库保留为普通 Markdown 链接，交给发布技能转换为文末引文。`资料与证据.md` 保存完整来源地图、主张清单、Figure 记录和未解决缺口；它是作者工作文件，不直接混入公众号正文。
