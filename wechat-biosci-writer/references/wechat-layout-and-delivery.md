# 微信排版与发布包

本文件定义平台无关的交付结构，以及与可选微信发布适配器的接口。写作技能只生成和验证文件，不创建微信草稿，不修改发布凭据或用户发布配置。

## 发现发布适配器与偏好

先检查运行环境是否提供用户指定的微信发布 skill、插件、命令或 API。存在时读取其当前接口说明，并在它声明的位置查找主题、配色、发布方式、默认作者和评论设置。不要假设操作系统、用户主目录或固定安装路径。

没有发布适配器或配置时，仍生成标准发布包；使用任务中明确的作者信息，并把缺失偏好列入 `发布前检查.md`。不要自行创建凭据或配置。`baoyu-post-to-wechat` 是一个兼容的可选适配器，但不是核心流程依赖。

## 固定目录结构

完整任务交付一个自包含目录：

```text
文章发布包/
├── 公众号文章.md
├── 公众号文章.html
├── imgs/
│   ├── cover.png
│   ├── figure-01.png
│   └── figure-NN.png
├── 资料参考图/
├── 图片方案.md
├── 资料与证据.md
└── 发布前检查.md
```

`公众号文章.md` 是默认发布入口。`公众号文章.html` 只用于人工预览，或用户明确选择 HTML 发布时作为备选；两者使用相同 basename，使 HTML 发布路径仍可从 Markdown 读取元数据。

`资料参考图/` 只保存许可尚不支持公开发布、但对作者分析有用的图片。Markdown 和发布 HTML 均不得引用其中的文件。

## Markdown 元数据

文件开头使用以下字段；字段名保持不变：

```yaml
---
title: "文章标题"
description: "不超过 120 个字符的摘要"
author: "共进化的十字路口"
coverImage: "imgs/cover.png"
sourceUrl: "https://论文或项目的单一权威入口"
---
```

- `title`、`description`、`author` 和 `coverImage` 必填。
- `description` 面向微信摘要，最多 120 个字符，不写引用标记。
- `coverImage` 固定指向实际存在且非空的 `imgs/cover.png`。
- 只有文章存在一个明确权威入口时填写 `sourceUrl`。多来源盘点或无法确定单一入口时省略。
- 发布技能也识别其他别名，但本技能只生成上述规范字段，降低交接歧义。

## Markdown 正文

- 正文图片统一放在 `imgs/`，使用相对路径：`![图 1｜原创图注](imgs/figure-01.png)`。
- 文件名使用小写英文、数字和连字符，避免空格；`cover.png` 名称固定。
- 外部来源使用可点击的普通 Markdown 链接。不要预先模拟微信脚注，也不要在写作阶段把正文转换成用于发布的 HTML。
- H1 只由文章标题承担；正文从 H2 开始。段落适合手机阅读，长段按判断与证据自然拆分。
- 代码块注明语言；长命令在语义完整处换行，不使用截图替代可复制代码。
- 表格只在行列比较明显优于文字时使用；宽表在 HTML 预览中提供横向滚动。

## 封面和图片工作文件

封面是完成条件。优先制作原创、版权清晰、在小尺寸仍可辨认的科研封面；不依赖“正文首图兜底”。只有许可或用户授权明确时，才把文献 Figure 用作封面。

`图片方案.md` 至少记录图片文件名、位置、功能、来源、许可状态、制作或裁切说明和替代文本。正文不用的候选图不要留在 `imgs/`。

## HTML 预览

从 `assets/wechat-article-template.html` 生成浅色预览。将模板占位符替换为已转义的标题、作者、摘要和渲染后的正文。最终 HTML 必须：

- 声明 `lang="zh-CN"`，包含非空 `<title>`、`meta name="author"` 和 `meta name="description"`。
- 使用适合移动端的视口设置与内联样式，不依赖远程 CSS 或 JavaScript。
- 图片仍引用 `imgs/` 下的相对路径。
- 正文只呈现读者内容，不混入来源清单、许可审计或质量检查。

## 发布前检查与交接

在技能目录中运行：

```text
python scripts/validate_package.py "文章发布包"
```

验证通过后，如运行环境提供用户选定的发布适配器，按其当前说明对 `公众号文章.md` 执行不创建草稿的 dry-run。dry-run 只验证适配器能解析内容，不能替代本技能对封面、相对路径和许可的检查。

`发布前检查.md` 记录：文章级别、默认发布入口、解析到的发布方式、主题、配色、作者、正文图片数、验证命令与结果、图片许可状态、尚未执行的人工检查。只有用户之后明确要求发布，才把 `公众号文章.md` 交给发布技能执行实际发布。
