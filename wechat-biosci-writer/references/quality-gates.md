# 质量门禁

完整文章按顺序通过以下门禁。失败时修复产物；无法修复时在 `发布前检查.md` 说明证据缺口和对结论的影响，不用“已完成”掩盖未验证项。

## G0｜任务与材料

- 已写清目标读者、快评或深解、文章帮助读者完成的任务。
- 已记录资料覆盖范围；仅摘要时没有伪装成全文解读。
- 标题、摘要和核心结论所需的名称、日期、版本、数字均有实际来源位置。

## G1｜科学证据

- `资料与证据.md` 含来源地图和关键主张清单。
- 实验结果、计算结果、作者解释、用户陈述和编辑推断已分开。
- 相关性未写成因果，预测未写成验证，预印本未写成同行评议定论。
- 重要比较说明基线、指标和适用条件；缺失参数、阈值、对照或外推条件已指出。

## G2｜级别完成度

快评应能回答：发生了什么、真正新意、核心证据、科研影响、当前边界；全文保持一个中心判断，不扩写成小综述。

深解应形成教学闭环：问题为何困难、方法如何处理、关键证据怎样支持、实践中如何开始或判断结果、哪些失败与边界仍存在。具体分支要求以 `teaching-deep-dive.md` 为准。

## G3｜Figure 与许可

- 每张发布图片在 `图片方案.md` 和 Figure 记录中可追溯。
- 已阅读原图注和相关正文，图注没有复制原文，也没有超出证据。
- `imgs/` 只含允许发布的图；许可不明确的原图只在 `资料参考图/`，且没有被 Markdown 或 HTML 引用。
- `imgs/cover.png` 实际存在、非空、小尺寸可辨，并有明确版权状态。

## G4｜原创性、结构与表达

- 正文从来源地图和主张清单独立组织，没有沿用第三方文章的独特标题结构、段落顺序、比喻、图注或辨识度高的句子。
- 必要直接引用范围短、使用引号并紧邻来源；其余内容以事实和证据为基础重新表达，而不是同义词替换。
- 标题准确体现来源身份、核心动作或区分度，不为了吸引力强塞数字或夸大结论。
- 开头迅速给出来源、问题、结果和本文判断；组件按内容重排，不套固定句式。
- 每个 H2 承担一个判断；证据、解释和限制相邻。删除重复背景、空泛意义和无功能配图。
- 计算概念首次出现时说明它在实际研究中解决什么问题；术语前后一致。
- 正文没有 Agent 自述、内部检查、许可讨论、提示词或请求反馈。

## G5｜发布兼容性

- 目录与文件名符合 `wechat-layout-and-delivery.md`；默认发布入口是 `公众号文章.md`。
- Frontmatter 必填字段完整，摘要不超过 120 个字符，单一来源入口才填写 `sourceUrl`。
- Markdown 和 HTML 中的本地图片路径均可读，且只引用 `imgs/`。
- HTML 含标题、作者、摘要、中文语言声明和移动端视口，不依赖远程样式或脚本。
- `scripts/validate_package.py` 退出码为 0；已安装发布技能时完成 dry-run 或记录无法执行的原因。

## G6｜草稿保护

仅在修改已有草稿时检查：修改强度符合授权；作者第一人称没有被 Agent 冒用；主要结构变化已记录；新增事实和图片都有来源。

## 完成记录

`发布前检查.md` 最后给出明确状态：

- **通过**：自动检查通过，人工许可与科学边界检查也已完成。
- **有条件通过**：文件可发布，但存在已披露的非阻断项，例如无法执行发布技能 dry-run。
- **不通过**：存在缺图、缺来源、许可不明、路径错误或会改变核心结论的问题。不得建议直接发布。
