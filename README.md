# My Skills

面向多种 Agent 的技能集合。每个一级子目录是一个可独立使用、修改和验证的 skill；核心流程使用通用 `SKILL.md`、`references/`、`assets/` 和 `scripts/`，平台专属元数据只作为可选适配层。

## 当前技能

- `wechat-biosci-writer/`：将生命科学论文、技术或草稿写成“快评”或“深解”两级微信公众号文章，并生成兼容微信发布流程的完整文章包。
- `novel-writing/`：长篇网络小说创作协作，覆盖开书立纲、日更写作、剧情讨论修改、角色代入推演，并提供选题扫榜和审稿去 AI 味检查。

## 版本管理约定

- 新 skill 放在独立的一级子目录中。
- 修改单个 skill 时，只暂存并提交该目录及与它直接相关的仓库级说明。
- 本地备份、验证临时文件、凭据和私钥不进入 Git。
- 推送前运行目标 skill 自带的验证，并确认没有凭据、私钥、本地备份或无权公开的资料进入 Git。
